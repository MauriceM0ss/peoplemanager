    Help & tips

    Keyboard

    Enter
    Submit the focused form (add person, task, …)
    Esc
    Close the open dialog

    Tips

    • Markdown works in Key details, Profile, conversation notes and notes.
    • Use ☰ to collapse the sidebar (desktop) or open it as a drawer (mobile).
    • Switch themes (Dark Terminal / Deep Blue / Light / GitHub / Amber) in ⚙ Settings → Appearance.
    • Organise people with categories: add, rename, delete or reorder them in ⚙ Settings → Categories, from any page.
    • Drag a person in the sidebar onto another category to move them there.
    • Auto-lock can be set to Never in ⚙ Settings → Security.
    • Back up regularly via Settings → Data → Export.
